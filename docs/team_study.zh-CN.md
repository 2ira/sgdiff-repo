# DATA8002 · 相同观测缺失下，哪些链接证据仍然可用？

本次八种方法的正式评测、SGDiff/SP4LP/Katz 三组消融、历史训练预算与实际产物见[统一实验协议](paired_reproduction.zh-CN.md)。

同一批论文对，预测它们在原图里是否有引用关系。边被转成无向边，所以预测的是“二者是否相连”。先把答案藏起来，在干净训练图上学一次，然后逐渐拿走模型能看到的上下文。在同一个数据集、同一个随机种子内，所有方法使用相同的训练、验证、测试查询和同一张扰动图。研究对象是测试时的证据损失。

## 四个人各讲两种方法

人名是根据会议记录中已有工作给出的分工建议。文档在这项任务下点名了三人，第四位由组内填写。八行主比较之外，三个方法各有两个组件对照。

| 建议负责人 | 方法与代码名 | 给它一对节点，它具体做什么 | 汇报时要回答的问题 |
|---|---|---|---|
| Jiawei | Common Neighbors，`cn` | 数 A、B 同时连着多少个节点。无需训练。 | 两个隐藏正例都没有共同邻居时，能区分吗？它们同得零分。 |
| Jiawei | 截断 Katz，`katz` | 把一至五步游走的条数乘上衰减权重后求和。游走可重复经过节点或边。 | 二跳已经用完共同邻居信息，三至五跳还能贡献多少排序信息？ |
| Jiatong | 属性余弦，`feature_cosine` | 比较两篇论文词向量的方向。丢失一端整行时约定得零分。无需训练。 | 为什么删光共同邻居它也能得原分？遮蔽后同分候选会变多。 |
| Jiatong | SP4LP，`sp4lp` | 一层 GCN 编码节点，两个端点的表示逐元素相乘；将一条最短路径的节点表示交给 Transformer，与端点分支拼接后打分。 | 模型从哪些地方读到属性？端点与路径上的表示都用到了 GCN。去路径也保留邻居聚合。 |
| Junxiong | GCN 图自编码器，`gae` | 两层 GCN 聚合邻居属性，算两个节点表示的内积；用真假节点对的二元交叉熵训练。复用 `fsd_none` 的 32→16 维编码器。 | 不显式找 A 到 B 的路径，删边为什么仍会改变预测？两端聚合到的邻居变了。 |
| Junxiong | FSD 第一阶段 + GAE，`fsd` | 用可见邻居传播属性，已观测行保持固定，再送入同一个 GAE。使用同学实现的 gamma=1.2、无额外类别监督版本。 | 补全能否胜过零填充？在干净训练中两者计算相同，直接共用参数。比较只能归因于这里的整套补全操作。 |
| 第四位 | PENCIL-style，`pencil` | 抽取两端的一跳子图，把节点属性、DRNL 结构角色和端点标记做成 token；用全注意力编码，再读出两端表示判别边。 | 即使注意力不直接按邻接矩阵屏蔽，删边为什么有影响？子图成员和角色标记都会变。仓库保留了 DRNL 与自定义读出。 |
| 第四位 | 修正后的 SGDiff，`sgdiff` | 在“有边”和“无边”两个假设下，分别计算局部结构与属性的条件扩散分数。学习两路权重，比较两类的融合分数。 | 结构分支高分和最终预测“有边”有什么区别？要比较两类的相对分数，融合权重也会影响结果。属性分支本身也使用邻接。 |

四个基础对照覆盖局部计数、多跳游走、属性相似性和邻居聚合。课程第 6 讲讨论共同邻居及按长度衰减的路径证据，第 10 讲可与图表示和链接预测联系起来。其余四个是论文方法或研究型适配。选 FSD 以检验显式补全，选 PENCIL-style 以便和 SGDiff 比较使用相近局部输入的判别与生成式打分。NCNC、LPFormer、Refined-GAE 另一个分支已有作者架构与组件报告，其训练批次目标遮蔽、部分位置编码与依赖环境不同，本轮把名额留给上述机制。

**一个讲解例子。** 假设 A、B 都引用 C，另有 A–D–E–B；A、B 的关键词都包括“图学习”。隐藏 A–B 后，CN 得 1，Katz 除了 A–C–B 还看得到三步游走。删去 A–C，CN 变 0，Katz 仍有三步证据，SP4LP 的最短路径会从两步变三步。词向量没变，属性余弦原分不动。如果同时把 A 的属性遮掉，余弦也变成 0；FSD 能否补回有用的方向，取决于尚可见的邻居。SGDiff 和 PENCIL 还要在新的局部子图上重新计算角色标记。这个例子说明输入机制，实际升降见结果表。

## 分工后的代码阅读顺序

- **Jiawei** 先看共同邻居的交集如何计算，再跟踪 Katz 循环中的向量：每乘一次邻接矩阵，就多走一步。用两跳输出与 CN 的逐查询排序做自检。[CN 评分](../sgdiff/engine/course_baselines.py) · [Katz 游走累加](../sgdiff/models/baselines/spectral_walk.py)
- **Jiatong** 从两篇没有共同邻居但词汇相似的论文出发，依次跟踪 `set_context` 抽路径、`encode` 聚合属性、`score_pairs` 融合打分。对照仅端点版本还保留了哪些参数。仓库适配的隐藏宽度为 64，路径序列最多保留 32 个位置；平衡随机负例与作者 HeaRT 评测的难度也不同。[SP4LP 适配器](../sgdiff/models/baselines/sp4lp.py) · [作者代码与版本说明](../sgdiff/vendor/sp4lp/PROVENANCE.md)
- **Junxiong** 先用 GAE 的内积写出两个端点的分数，再跟踪某个被遮蔽节点的一行属性如何由 FSD 填补。关注邻居也没有可用属性的情况，以及已有观测行在传播后如何恢复。两者共享完全相同的预测器，适合一起讲。[GCN 与内积](../sgdiff/models/baselines/node_pair.py) · [FSD 补全](../sgdiff/models/baselines/fsd.py)
- **第四位** 取同一对端点的一跳子图，画出该子图中各节点相对两端的位置。先看 PENCIL-style 怎样把这些输入直接映射为类别分数，再看 SGDiff 怎样在两个类别假设下打分及融合。最后读训练日志里两个阶段的验证损失，比较“分支给了多少信息”与“模型目前是否学好”这两个问题。[PENCIL-style](../sgdiff/models/baselines/pencil.py) · [SGDiff 两路打分](../sgdiff/models/sgdiff.py) · [融合](../sgdiff/models/fusion.py) · [训练与选权重](../sgdiff/engine/trainer.py)

## 统一协议

- 比较 Cora、CiteSeer 的无向链接。沿用近期同学共同用过的两张图。随机种子 0、1、2，各自重新分出正边 80/5/15，负例从全图非边固定抽取，三份互斥。训练、验证的可见边来自训练集，推断图可见训练及验证正边。固定同一份平衡查询子集。所有测试正负候选和验证负例均禁止被插入。节点类别仅供 DICE 构造扰动。
- 统一使用 **0%、25%、50%**。每个非零比例七个条件，共 15 个。以隐藏测试边后的可见无向边数 E 为分母，预算为 round(rE)。纯删边精确删掉整个预算。RF 和 DICE 的预算是总编辑数，删除取预算一半向下取整，其余用于插入。
- 七个条件分别为均匀删边、低度偏向删边、RF、DICE、整行属性遮蔽、均匀删边加属性遮蔽、低度删边加属性遮蔽。低度权重取 1/(1+min(dᵤ,dᵥ))，度在干净可见推断图上计算，加权无放回取样。DICE 删除同类边并插入跨类边。整行遮蔽精确选 round(rN) 个节点，联合条件与对应单因素共用边和行。EA 保留在原仓库攻击评测；这里集中比较删失与属性互补，历史 10/20/40% 和 EA 结果单独引用。
- 同一模型冻结参数。CN、Katz、最短路径、GCN 表示、FSD 补全、子图与 DRNL 都在当前图上重算。属性余弦、子图模型读取原始属性；全图神经编码器的标准化统计固定自干净属性，遮蔽行在各自的输入空间置零。FSD 知道哪些行被遮蔽。SP4LP 的训练路径隐藏当前目标边，全图 GCN 的训练邻接保留训练正边，子图模型对当前查询移除目标边。测试候选对所有模型都不可见。
- 主指标 AUROC、AP；记录绝对分数和同种子 clean 减去扰动后分数。0.05 相当于 5 个百分点。三个种子的离散度报样本标准差。随机平衡负例下 AP 的基线约为 0.5，评价只描述这个候选集。每个条件另存编辑数、遮蔽数、图指纹、孤立节点以及至少一端孤立的查询比例。
- `local` 每个数据集/种子使用 256 条训练、128 条验证、128 条测试查询，各一半正例。SGDiff 使用数据集配置的扩散步数和网络宽度，子图最多 16 节点、两路 MC=2，扩散训练 4 轮加冻结扩散的融合训练 4 轮。PENCIL-style 最多 10 轮；GAE、SP4LP 最多 30 轮。干净验证集用于选权重，各模型沿用其训练器的选择规则。这个预算能完成整套配对实验，无法判定模型的充分训练上限。
- `team` 档供扩大样本的同协议复跑：训练总上限 2,000，验证和测试各总上限 1,000（各类最多 500，受原始划分限制），子图最多 40 节点、MC=4、SGDiff 8+8 轮、PENCIL-style 最多 40 轮、GAE/SP4LP 最多 200 轮。两档分别汇总。

正式比较默认采用 `paper-rq3`，与 Cora 鲁棒性主表的 SGDiff clean AUROC **0.8582** 对齐训练与干净评分设置。使用完整训练划分和原始模型配置；测试取前 500 正、500 负，两组各自重置评分 RNG。统一入口还可选择 `reference`，用于复核 Line C / SP4LP 的另一套预算：2,000 训练对、验证最多 500 对、测试每类最多 500 对，SGDiff 最多 8+20 轮，SP4LP 最多 300 轮。各档单独汇总。新协议的低度删边或属性遮蔽结果需要在相应档位重新测量。[逐种子依据与实测预算敏感性](../results/team-study/budget-audit/README.md)

## 三组消融应该怎样读

| 完整方法 | 两个对照 | 能回答的问题 |
|---|---|---|
| Katz 五跳 | 最多两跳、最多三跳 | 固定当前图的 β=0.85/max_degree，只改变求和截断处。在目标边隐藏时，两跳和 CN 的排序应相同。跨扰动图 β 会随最大度重算。 |
| SP4LP | 仅端点；全节点属性改常数 1 | 两个变体都在同一份干净训练数据上重新训练。前者移除路径并更换读出头；后者保留路径但拿掉原始属性。因此差值包含适应训练和容量变化。 |
| SGDiff | 只保留结构项；只保留属性项 | 同一冻结模型、同一子图、同一轮抽样先算出两路分数，再分别用原融合权重保留一路。回答“当前模型在测试时靠哪路打分”；独立单分支重新训练是另一项实验。属性路仍有结构条件。 |

读表时先看绝对分数，再看相对 clean 的下降。讨论组件用每个种子的“完整减变体”，再跨种子平均；讨论缺失机制用同一模型、同一种子的“随机删边减低度删边”。干净表现接近随机的模型即使变化很小，也很难据此主张实用鲁棒性。

## 代码与复跑

从仓库根目录运行。数据首次下载后缓存，PyTorch 与 PyG 版本应与设备相容。

```bash
python -m pip install -e '.[investigation,dev]'
python scripts/run_team_study.py --datasets cora citeseer --seeds 0 1 2 --profile paper-rq3 --device cpu --output runs/team-replay
python scripts/summarize_team_study.py runs/team-replay/paper-rq3
python scripts/summarize_team_study.py results/team-study/local
```

`fit_all` 接收同一 split 与实际训练/验证/测试数据集。`predict_all` 接收冻结模型、当前图、同一批候选对、标准化属性和行观测掩码，返回各模型与变体按输入顺序排列的一维分数。汇总脚本只读按种子保存的查询、标签、分数和 manifest；用 sklearn 复算两个指标，检查完整覆盖、图无关对照、Katz 两跳等价性、联合条件一致性，并输出均值、标准差和成对差值。更换 `--output` 可保留独立复跑。不同档位或不完整的种子组不能拼成一张均值表。

分支基线为 `feat/part2-sp4lp-katz-aligned@d3b720d`，已包含 `main@d4b150c` 修正 SGDiff、`feat/line-c-fsdcap@fd8d9e1` 的补全模型，以及 SP4LP 与谱/游走分支中的 Katz 实现。前期小组表格用过训练前固定遮蔽、不同测试可见边和不同查询预算。新表仅汇总本入口的结果。
