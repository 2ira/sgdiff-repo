# 当前结果：建议做“低核验预算下区分真实互惠与测量相关性”

已有文献足以排除“首次把漏边/误报加入 probit 或网络模型”的宽泛创新主张。
本轮更有价值的增量是：在同学的四状态 collapsed 计算框架上，引入核验数据，
区分噪声校正、后验近似和测量错误依赖结构，并提供可复现的失败与修复证据。

## 已完成的证据

基础与扩展共 1,230 个场景--重复单元，包含 n=30/60/120/300、核验比例、相对稀疏、
强/弱互惠和两种模型误设。场景间共享种子以便配对，不能把所有单元当相互独立。
另在已有网络上运行核验设计、200 次 rho 一维积分、300 次完整通道拟合。

| 对比（rho） | RMSE | 95% 区间覆盖率 | 解释 |
|---|---:|---:|---|
| 中等独立错误，Naive | .698 | 0% | 忽略错误严重扭曲互惠 |
| 同场景，Joint + 5% 核验 | .157 | 85% | 校正有收益，区间仍欠覆盖 |
| 同场景，rho 积分 | .141 | 93% | 保留偏斜可改善区间；点估计改用后验均值 |
| 较强独立错误，Joint | .206 | 85% | 仍有信息损失与近似问题 |
| 同场景，rho 积分 | .185 | 96% | 计算更贵，不代表所有场景都已校准 |
| 方向相关错误，独立通道 Joint | .183 | 0% | 将测量相关性误认为真实互惠 |
| 同场景，完整四状态通道 | .073 | 95% | 当前最明确的组件修复证据 |

以上均为每场景 100 次重复。93%、96%、95% 的 Wilson 区间分别为
[86.3%,96.6%]、[90.2%,98.4%]、[88.8%,97.8%]，不能视为保证名义覆盖。

## 必须同时呈现的代价和负结果

- 完整通道在独立错误下 RMSE 从 .157 上升到 .175，覆盖仍为 85%。
- 协变量异质错误下，完整通道 RMSE .306，覆盖仅 51%；同质通道没有解决异质性。
- 同一个联合 mode 的条件/边缘协方差消融，仅使中等错误覆盖从 82% 到 85%；
  较强错误均为 85%。不能把主要收益归因于协方差传播。
- 均衡观测状态分层没有显示优于同预算随机核验。RMSE 差值的配对 bootstrap
  区间都包含零；这不是信息最优核验的检验。
- 强互惠 rho=.95 时普通 Joint 的覆盖只有 51%；相对稀疏时为 75%。
- n=300 的 Joint RMSE .023、覆盖 96.7%，但仅 30 次重复，区间很宽。
- 未使用真实数据，完整通道尚无多链后验验证；积分和完整通道是看到初始结果后
  追加的探索性分析，不是预先登记的确认性结论。

## 最值得继续的研究问题

1. 用低维相关错误通道（例如一个依赖参数），获得完整 12 参数通道的主要收益，
   降低少核验时的方差和先验依赖。
2. 针对“rho 与测量相关性可区分性”设计核验目标；和随机、观测分层进行同预算比较。
3. 引入协变量相关的误报/漏报率，同时检查识别、先验敏感性和区间校准。
4. 在保留的模拟场景及真正的人工复核/重复测量网络上验证。

当前适合定位为方法适配、失败机制与实证边界；若要形成更强方法论文，仍需新的
识别/核验设计结果，或有说服力的真实应用。来源与查新范围见 RESEARCH.md。
