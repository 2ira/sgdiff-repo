# Main input/attack protocol supplement, including PubMed

Read the [complete measured report](report.md) for figures before all result
tables, or [the protocol and commands](../../REPOSITORY_PROTOCOL.zh-CN.md).
Completion and verification status are recorded in [audit.json](audit.json).

The formal matrix is Cora/Citeseer/PubMed × NCNC/LPFormer/Refined-GAE × full model
and two retrained component variants × seeds 0/1/2: **81 fresh trainings**.
Cora/Citeseer each have clean + RF/DICE/EA at 10/25/50%; PubMed has clean + RF/DICE.
Main's EA node limit excludes PubMed. The resulting matrix has **729 evaluations**.

- `summary.csv`: all 243 aggregate rows, mean and sample SD over three seeds.
- `per_seed.csv`: all 729 evaluations and paired clean-to-attack drops.
- `paired_components*.csv`: full-minus-variant performance and variant-minus-full
  degradation. The paired summary has 162 rows; compare both definitions.
- `attacks/`: **81 shared inference graphs**, including clean; each original NPZ
  has `raw_edges` (main's complete attacked graph), `edges` (test positives then
  removed), and JSON `statistics`. No test-negative protection is added.
- `splits/`: nine full train/validation/test splits, plus the exact first500
  positives and first500 negatives used in scoring.
- `input_manifest.json`: exact graph/data/source fingerprints, realized edits
  before and after test-edge removal, and PubMed EA skip records.
- `run_manifest.json`: all81 configurations; author architecture/optimizer
  choices are explicit and differ from the older native baseline trainers.
- `training_summary.csv`: selected/stopped epochs, checkpoint hashes, timing and
  per-process allocated GPU memory. Initial PPR preparation is outside timing.
- `replay_audit.json`: independently reloaded81 checkpoints,162 evaluations,
  observed score/metric differences and tolerances.
- `data_manifest.json`, `runtime.json`, `ppr_reuse.json`: pinned raw data,
  environment/source versions and reuse of reference-equivalent exact-graph PPR.
- `full_models`, `attack_curves`, `component_effects`: integrated PNG/PDF figures.
- `checksums.sha256`: integrity hashes; `verify.py`: a NumPy-only verifier.

```bash
python experiments/new_link_models/benchmarks/repository_protocol/verify.py
```

Load an already attacked inference graph directly, without attacking it again:

```python
from pathlib import Path
import json
import numpy as np

root = Path('experiments/new_link_models/benchmarks/repository_protocol')
with np.load(root / 'attacks/pubmed_s0_rf_0.25.npz', allow_pickle=False) as f:
    edges = f['edges']  # inference edges, after test-positive removal
    stats = json.loads(str(f['statistics']))
with np.load(root / 'splits/pubmed_seed0.npz', allow_pickle=False) as f:
    test_pos, test_neg = f['scored_pos'], f['scored_neg']
edge_index = np.concatenate([edges, edges[:, ::-1]], axis=0).T
```

Use `edges` for inference; `raw_edges` is only for auditing the complete attack
and still contains held-out positives that the attacker did not remove. Restore
node counts and raw attributes from the same main dataset loader (PubMed:19717
nodes,500 features), then apply main's `node_feature_matrix` standardization.
Graph snapshots do not replace the attributes with degree features. Recompute
LPFormer PPR for the selected inference graph.

These graphs were newly generated by main at commit
`d4b150c121625001f52ead23abf15aead1a4b665`; they are not claimed to equal historical
H20 runs or a collaborator's cache. To merge comparisons, share these graph
snapshots and test pairs or verify the other cache's hashes first.

The [older protected-target EA snapshots](../ea_graphs/README.zh-CN.md) belong to
a separate experiment and contain insertion-only EA edits. Do not mix them with
this directory's main-protocol EA, which retains the original deletion/insertion
allocation. PubMed EA has no cache file here because it was skipped.

The original main node-pair validator sees train+validation edges, including
validation positives; this supplement explicitly reproduces that behavior.
Model optimization still uses documented author recipes (max100 epochs,
batch512 target masking), not a claim of identical trainers or paper-table parity.
Model weights, raw attributes and large PPR caches remain in the external output
directory; graphs/splits and every measured result are included here.
