## GAE 的鲁棒性与组件消融

本组正式汇总共 1,134 组：3 个方法，每个方法 1 个完整版和 2 个消融版，2 张图、3 个种子、21 个条件。每组对同一批 1,000 个候选链接打分。[三种方法全部 AUROC/AP 及标准差](owned-tables/summary.csv) · [逐种子指标](owned-tables/per_seed.csv) · [配对组件差值](owned-tables/components.csv) · [按端点度分组](owned-tables/endpoint_degree.csv)

## 同样删掉一半边，谁更受影响？

按每个查询在**干净训练图**中较小的端点度固定分为 0–1、2–3、4+ 三组。在 Cora，完整 SP4LP 的整体 AUROC 在低度删边和随机删边下接近（0.833、0.831）。但只看端点度 0–1 组，低度删边为 0.773，随机删边为 0.793，干净为 0.877；4+ 组则依次为 0.888、0.872、0.922。整体均值掩盖了两个组相反的排序。各分组独立计算 AUROC，组内值的均值不能还原整体 AUROC。每组的正负查询数及逐种子指标随表提供。[端点分组结果](seven-methods/tables/endpoint_degree.csv)

本地 SGDiff 种子 0 的首个融合校准权重也已单独归档。该权重在 Cora 的固定 1,000 个测试对上实测 clean AUROC 0.8678。完整/单分支的分数、随机和低度删边结果可用共享接口复验。[训练中间检查点及三个组件读出](sgdiff-milestone/README.md)
