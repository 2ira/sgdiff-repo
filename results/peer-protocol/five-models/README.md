# 五模型在 Junxiong 第一版 EA 原图上的比较

**更新**：[SP4LP 全量训练后的五模型比较](../../sp4lp-full-training/README.md#五模型在相同输入上的比较)已完成。新旧测试对、攻击图和原生评测入口保持一致，下表保留旧版 SP4LP 训练的历史分数。新版包含全部正式检查点、训练曲线及两项独立重训消融，仍需结合训练预算差异解释跨模型排名。

Cora、CiteSeer 各三个种子，每个种子评 EA 10%、25%、50%。本次用原图重新计算了 Katz、SP4LP 及四个消融的 108 组预测，沿用干净条件的冻结权重。NCNC、LPFormer、Refined-GAE 的成绩取自 Junxiong 第一版逐种子表。两组使用相同的测试对、受扰动的图及指标函数，各模型的训练配方和预算沿用原实验。[第一版评测记录](https://github.com/2ira/sgdiff-repo/blob/95083da808e500c02da458e205f4b861ceb80871/experiments/new_link_models/benchmarks/per_seed.csv) · [发布的原图、划分和清单](https://github.com/2ira/sgdiff-repo/tree/5d8242701e2325b2dec8461a16d3b4963876b892/experiments/new_link_models/benchmarks/ea_graphs)

## 训练配置对排名的影响

这些成绩比较各自已训练配置在同一评测输入上的表现。SP4LP 使用宽度 64 的单层 GCN 和单层 Transformer；训练损失仅使用 1,000 个正对和 1,000 个负对，完整训练图仍用于节点传播。在 Cora，原训练划分含 4,222 个正对；CiteSeer 为 3,641 个正对。Junxiong 第一版的三个学习模型遍历完整训练正负对，并按批次更新参数。本组 SP4LP 则在每轮内累积所有批次的梯度，再更新一次参数，最多 300 轮，以验证 AUROC 每 5 轮选一次权重，连续 6 次未提升即停止。现有 SP4LP 检查点保存了配置、权重和指标，缺少逐轮历史与最佳轮数，所以实际训练轮数和是否充分收敛仍待实证核验。[本组训练器](../../../sgdiff/engine/course_baselines.py) · [检查点保存逻辑](../../../sgdiff/engine/reproduction.py) · [Junxiong 的训练器](https://github.com/2ira/sgdiff-repo/blob/95083da808e500c02da458e205f4b861ceb80871/experiments/new_link_models/run.py#L54-L110)

SP4LP 论文表 1 使用 HeaRT 的困难负例和 MRR、Hits@K。这里使用随机负例及 AUROC、AP，模型排序可能改变。论文附录表 10 为 Cora/CiteSeer 列出隐藏维度 128，所固定作者仓库的 Cora 配置则为 256，本组为 64。这些配置存在差异，后续忠实复现需要明确采用的论文或代码版本。现有表格可以支持本配置下的鲁棒性和组件分析；验证 SP4LP 方法在该任务上的充分训练表现，需要补做完整训练样本、作者配置和带逐轮日志的训练对照，并以验证集选择配置。[论文实验设置](https://arxiv.org/html/2507.07138v2#A4) · [固定作者 Cora 配置](https://github.com/francescoferrini/sp4lp/blob/1b664cbb91eb0b88f7c99dca20754664f92632d0/configs/cora.json)

## 完整模型

各格为三个种子的平均 AUROC / AP，均按 0–1 展示。最后一列为同种子干净 AUROC 减 EA 50% AUROC 的平均差，单位为百分点。

### Cora

| 方法 | 干净 | EA 10% | EA 25% | EA 50% | AUROC 降幅（百分点） |
|---|---:|---:|---:|---:|---:|
| Katz | 0.8434 / 0.8580 | 0.8412 / 0.8568 | 0.8360 / 0.8542 | 0.8214 / 0.8463 | 2.20 |
| SP4LP | 0.9141 / 0.9265 | 0.9116 / 0.9236 | 0.9071 / 0.9194 | 0.8953 / 0.9090 | 1.88 |
| NCNC | 0.9592 / 0.9578 | 0.9552 / 0.9545 | 0.9512 / 0.9509 | 0.9435 / 0.9444 | 1.56 |
| LPFormer | 0.9361 / 0.9438 | 0.9306 / 0.9396 | 0.9244 / 0.9348 | 0.9158 / 0.9264 | 2.03 |
| Refined-GAE | 0.9616 / 0.9597 | 0.9580 / 0.9568 | 0.9533 / 0.9526 | 0.9452 / 0.9460 | 1.64 |

### CiteSeer

| 方法 | 干净 | EA 10% | EA 25% | EA 50% | AUROC 降幅（百分点） |
|---|---:|---:|---:|---:|---:|
| Katz | 0.7778 / 0.7828 | 0.7786 / 0.7839 | 0.7771 / 0.7833 | 0.7745 / 0.7831 | 0.34 |
| SP4LP | 0.9133 / 0.9308 | 0.9088 / 0.9269 | 0.9034 / 0.9222 | 0.8948 / 0.9141 | 1.85 |
| NCNC | 0.9683 / 0.9697 | 0.9638 / 0.9658 | 0.9591 / 0.9611 | 0.9500 / 0.9528 | 1.82 |
| LPFormer | 0.9435 / 0.9488 | 0.9408 / 0.9472 | 0.9384 / 0.9449 | 0.9317 / 0.9401 | 1.18 |
| Refined-GAE | 0.9651 / 0.9663 | 0.9628 / 0.9643 | 0.9600 / 0.9618 | 0.9533 / 0.9564 | 1.18 |

在 EA 50% 的三种子均值上，Refined-GAE 在两张图的 AUROC 和 AP 都最高。Cora 的前两名很接近，Refined-GAE 与 NCNC 的 AUROC 分别为 0.9452 和 0.9435。CiteSeer 上，干净条件由 NCNC 领先，到 EA 50% 时 Refined-GAE 领先。这里比较的是点估计。Katz 在 CiteSeer 上从干净到 EA 50% 仅下降 0.34 个 AUROC 百分点，但干净和受扰两种条件下，它的绝对 AUROC 均居五种方法末位。

## Katz 与 SP4LP 组件消融

表中为平均 AUROC。Katz 的完整配置累计最多五步游走。SP4LP 的仅端点、无原始属性版本各自沿用此前独立训练的权重。各预算下的配对组件差值及样本标准差见[全条件汇总](summary.csv)。

| 配置 | Cora 干净 | Cora EA 50% | CiteSeer 干净 | CiteSeer EA 50% |
|---|---:|---:|---:|---:|
| Katz 五步 | 0.8434 | 0.8214 | 0.7778 | 0.7745 |
| Katz 三步 | 0.8014 | 0.8031 | 0.7563 | 0.7587 |
| Katz 两步 | 0.7219 | 0.7321 | 0.6688 | 0.6892 |
| SP4LP 完整 | 0.9141 | 0.8953 | 0.9133 | 0.8948 |
| SP4LP 仅端点 | 0.8879 | 0.8691 | 0.9211 | 0.9073 |
| SP4LP 无原始属性 | 0.8949 | 0.8720 | 0.8518 | 0.8345 |

- **Katz** 的五步版本在两张图的 EA 50% 上都高于两步版本，分别高 8.93 和 8.53 个 AUROC 百分点。两张图上，五步相对两步的优势较干净条件缩小。
- **SP4LP** 在 Cora 的 EA 50% 上，完整版比仅端点高 2.62 个百分点；在 CiteSeer，同一对照中仅端点高 1.25 个百分点。去掉原始属性则在两图上都降低表现，EA 50% 时分别损失 2.33 和 6.03 个百分点。

## 输入和结果核验

- 18 份 EA 缓存逐字节匹配原图发布提交；实际边数组指纹逐张匹配第一版审计。6 份划分的训练、验证、测试正负对逐元素一致。测试正负对和验证负对都受到保护。Cora 三档分别插入 449、1,122、2,243 条边，CiteSeer 分别插入 387、967、1,934 条。18 张图均未删边，因此本页的结论限于这批 EA 编辑。
- 108 组新预测均从保存的逐对分数复算 AUROC、AP、Hits@100 和 Precision@100。自己的 396 组非 EA 记录与上一版完全一致。第一版五种完整模型在两个数据集的全部 14 个条件都可逐图比较。第一版三模型与本组交集为 Cora 和 CiteSeer，PubMed 另见[本组扩展](../pubmed/README.md)。
- [分种子结果](per_seed.csv)共 1,260 行，覆盖五个方法各自的完整模型与两个变体。[汇总表](summary.csv)包含三个种子的均值、样本标准差、相对干净条件的降幅、完整版减消融的配对差值。[18 张图核验明细](ea_graph_checks.csv) · [逐对预测和实际图](../predictions-and-graphs.zip)。
