机制归因：每个模型到底在读图的哪个性质

把 RF / DICE / EA 这类「删边 + 插边」混合攻击拆成定向探针，再用启发式可用性、分数对齐和组件消融把伤害归因到具体部件。核心结论：哪些攻击致命，取决于模型读的是什么性质，以及图有多稀疏。

06归因结论

同预算，不同信号

随机删边与按度删边删掉一样多的边（2253 vs 2256），但前者保留度信号、后者专杀它——同一预算下必须看「动了哪个性质」，而不是「动了多少边」。

度启发式 AUC：clean 0.639 → del 0.594 → del_hub 0.510；共同邻居 AUC：0.729 → 0.570 → 0.559

GCN 族的命门是特征，不是聚合

全图内积解码器把结构当平滑算子、把属性当信号：置零特征后全部跌到 0.43–0.50，而删边只掉 0.04–0.10。唯一例外是 GAT——逐目标 softmax 归一化让它对删边敏感 2 倍，也让同配插边变成增益。

GCN：clean 0.828 / 特征置零 0.433 / del +0.048 / del_hub +0.056；GAT del +0.097，ins_homo -0.019

子图族死于「输入饥饿」

测试边在提取前就被移除，k=1 时唯一判据是共享邻居路径。删边把这条路径砍掉七成，子图从 10.7 节点缩到 5.4–7.0；插边不删证据，几乎无损。

共享邻居率 clean 0.227 → del 0.068 → del_hub 0.053；SEAL del +0.142 / ins +0.025

SGDiff：只有结构分支在说话

融合支路的开关证明特征支路是死的（只留特征 = 随机），因此它对 feature_shuffle 免疫、对删边最脆弱，且脆弱点不是权重而是判据本身：两类似然之差在证据变薄时向先验坍缩。

clean 0.745 / 只用结构 0.744 / 只用特征 0.515；del +0.236（seed 波动 ±0.090）

密度决定「哪一半」致命

同样的 50% 删边，稀疏图上砍掉七成本地 2 跳信号，密集图上只砍掉三成：子图族的删边脆弱性是稀疏性的函数，不是权重的属性。密集图上换成 hub 插边才致命，因为它摧毁的是「度归一化」连通性。

Cora 共享邻居率 −70% → SGDiff del +0.236；USAir −28% → SGDiff del +0.036；USAir Jaccard AUC 0.897 → 0.640，PENCIL ins_hub +0.190

「看起来合理」的边几乎隐形

同配插边把同配性抬到 0.881（高于 clean），对所有模型伤害 ≤0.04，对 GAT 甚至是增益；只有异配边（最不合理的边）才带来 0.02–0.05 的伤害。没有模型直接读同配性——它只是平滑假设。

同配性 clean 0.811 / ins_homo 0.881 / ins_hetero 0.511；ins_hetero 最坏 +0.049（VGAE）
