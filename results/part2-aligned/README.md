# Part 2 aligned SP4LP/Katz study

This directory contains the completed CUDA runs for Cora and Citeseer under
complete attributes and a fixed 40% whole-node feature mask. Each native JSON
contains seven models/ablations, three seeds, and ten clean/attack conditions.

- `cuda-local/robustness_*_cuda.json`: final full-precision CUDA run records.
- `cuda-local/robustness_*_cuda.md`: compact AUC tables generated by the harness.
- `cuda-local/part2_aligned_auc.csv`: tidy CUDA AUC means, deviations and drops.
- `cuda-local/part2_aligned_ablations.csv`: paired CUDA component deltas.
- `cuda-local/environment.json`: exact local CUDA runtime provenance.
- `cpu/`: retained preliminary CPU runs; not the final aligned comparison.

The interpretation and evidence boundaries are in
[`docs/part2_sp4lp_katz_aligned.md`](../../docs/part2_sp4lp_katz_aligned.md).
Regenerate the derived files with:

```bash
python scripts/analyze_part2_aligned.py
```
